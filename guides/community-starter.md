# Community Starter Setup Guide

Thanks for using this template! Follow the steps in order and you'll have a polished, working server.

## 1. Set up the member counter

1. **Invite the ServerStats bot** to your server.
2. Run the **/counter create** command, choose **Members and Bots only**, and set the channel type to **Voice Channel**.
3. Use **/counter change** and its arguments to switch the counter's format to the one that reads **Discord Members:**.

## 2. Set up the info embed

1. Open **Discohook** and load the share link: https://discohook.app/?share=vM12AL1g
   *(Share links can expire. If it's dead, let **mario118118** on Discord know.)*
2. In your server, go to the **info channel** and create a **webhook**. Give it a name and an icon.
3. Copy the webhook URL and paste it into Discohook.
4. **Important: edit the embed before sending.** It's only a template, so you must:
   - Add **your own name**.
   - Optionally add your **sponsor** in the sponsor section. If you don't have one, delete that section.
5. Send the embed to the info channel.

New to Discohook? Search YouTube for a tutorial, or watch this quick one: https://www.youtube.com/watch?v=aKb1i8p7_4Y. It may be a bit outdated, but you'll still get the gist.

## 3. Add a ticket bot

Invite a ticket bot such as **Tickety**, **Ticket Tool**, or another of your choice. Each has plenty of setup tutorials online. Keep the panel and ticket styling clean and modern so it matches the rest of the server.

## 4. Add Dyno and set up auto role

Dyno is a must-have. Invite it, then set up an **Auto Role** that gives new members the grey **Member** role automatically.

## 5. Roles and staff

- **Every time you invite a bot, add it to the Bots role.**
- In **Server Settings → Roles**, you'll find plenty of ready-made staff roles, such as **Public Relations** and the other main staff roles. Assign them to your team as needed.

That's it, your server is ready to go! 🎉
