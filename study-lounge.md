# Study Lounge Setup Guide

> This is a sample guide. Replace it with the real steps for your template.

## 1. Add Dyno

Invite **Dyno** and set up an **Auto Role** so new members get the starter role.

## 2. Set quiet hours

Pin your quiet-hours schedule in **#rules** so members know when voice rooms are for focus only.

## 3. Review roles

Open **Server Settings → Roles** and assign moderators.
